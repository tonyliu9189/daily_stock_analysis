# 短期自動排程驗證

此測試用來確認 GitHub 是否會替既有每日工作流程建立真正的 `schedule` 事件。手動執行不算通過。

- 正式分析維持平日台灣時間 18:00，手動模式仍可使用。
- 短期探測排程為每小時第 7、22、37、52 分；GitHub 可能延遲，這些是預定時間。
- 探測使用獨立佇列，不會取代正式或手動分析的等待任務。
- 探測事件只執行 `schedule_probe`，記錄事件類型、cron、UTC 與台灣時間；正式 `analyze` 工作會跳過。
- 探測不讀取 Secrets、不安裝依賴、不呼叫模型、不送出通知，只有唯讀儲存庫權限。
- 觀察最多一小時；取得兩筆成功的自動探測，或時間到期後，即移除測試 cron、探測工作與正式工作的暫時條件，並刪除此文件及暫時 CHANGELOG 項目。
- 清除由本次操作負責執行並核對遠端，不是工作流程會自行刪除。不可留下測試排程等待日後處理。
- 成功表示目前這支工作流程能收到自動排程事件，不保證明日準點，也不直接證明先前停跑的歷史根因。
- 觀察時間內沒有事件，只能記錄該時間範圍未觸發，不能單憑這點斷言歷史原因。

本次測試不新增永久設定，也不更動上游更新流程。
